# WSH Council reference bulletins

These Workplace Safety and Health Council bulletins set the target depth for Singapore operational notes in the monthly digest ([spec 47](../specs/47_WSH_Digest_and_Alerts.md)).

| File | Series | Use |
|---|---|---|
| `20241213_wsh_alert.pdf` | WSH Alert | Fatal sequence, earlier cases the bulletin names, numbered controls, preliminary investigation note. Scanned pages only. The live series publishes an HTML “view in browser” page. The digest does not OCR image PDFs. |
| `20261007_wsh_advisory.pdf` | WSH Advisory | One hazard class (concrete pumping), several accidents, seven “what companies should do” steps, named regulations. |
| `20261008_WSH_Insights.pdf` | WSH Insights | Sector problem plus inspection push, good practices, long resource list. |

Automated tests use the fixtures in `tests/fixtures/wsh/`. Do not use these PDFs as test fixtures.
